# Performance

## القرارات

| القرار                                    | السبب                                                                                                                                                                                                                     |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| كل الصفحات Static/ISR                     | HTML جاهز من الـ cache، بلا انتظار للـ API أو قاعدة البيانات                                                                                                                                                              |
| Server Components افتراضياً               | مكونا عميل فقط في الموقع: قائمة الموبايل ونموذج التواصل                                                                                                                                                                   |
| لا مكتبات UI/animation/icons              | الأيقونات SVG inline تُرسم على الخادم (0 KB JS)                                                                                                                                                                           |
| الحركة CSS فقط (scroll-driven, transform) | بدون JS، لا تؤثر على LCP أو التباين، تحترم `prefers-reduced-motion`                                                                                                                                                       |
| خط محلي (`next/font/local`) بوزنين        | نص الـ LCP يعتمد على الخط؛ preload للعربية واللاتينية معاً (المسافات والأرقام في الملف اللاتيني، واكتشافه متأخراً أخّر LCP على الموبايل). محلياً لا يفشل البناء ولا يسقط إلى Arial إذا كان الاتصال بـ Google Fonts بطيئاً |
| `experimental.inlineCss`                  | Tailwind ≈ 8 KB gzip؛ إزالة طلب CSS يحجب الرسم لزوار أول مرة (الجمهور الأساسي)                                                                                                                                            |
| رسم الـ hero CSS فقط                      | عنوان الـ hero نص يُرسم فوراً؛ الرسم الزخرفي (الرمز ومداره) CSS/SVG بلا صور، ومخفي على الموبايل                                                                                                                           |
| الحركة تنتهي خلال 5 ثوانٍ                 | transform/opacity فقط، لا حلقات لا نهائية تستهلك المعالج أو تشتت القارئ                                                                                                                                                   |
| `next/image` + AVIF/WebP + `sizes`        | صور بالحجم المناسب لكل شاشة، cache 30 يوماً                                                                                                                                                                               |
| أبعاد ثابتة لكل صورة/حاوية                | CLS = 0                                                                                                                                                                                                                   |
| لا `loading.tsx` في الموقع                | الصفحات static؛ يحافظ على حالة 404 الحقيقية                                                                                                                                                                               |

- Mobile = المحاكاة الافتراضية لـ Lighthouse/PageSpeed (4G بطيء + معالج أبطأ 4×). LCP المحاكى ≈ 2.9–3.1s، TBT ≈ 20ms. المدى بين قياسات متكررة (ضوضاء القياس على نفس الجهاز).
- قبل الهوية الجديدة كان Mobile ‏86–90؛ التحسن من الخط المحلي و preload الملف اللاتيني.
- في متصفح حقيقي بدون تقييد: **FCP = LCP ≈ 180–320ms**.

## ميزانية الأداء

- JavaScript للصفحة: ≤ 160 KB (حالياً ≈ 153 KB، أغلبه React/Next runtime).
- لا `"use client"` جديد بدون قياس أثره.
- لا صور فوق الـ fold بدون `sizes` صحيح؛ `preload` لصورة الـ LCP فقط.
- CLS = 0 إلزامي.

## كيف تقيس

```bash
npm run build && npm start
npx lighthouse http://localhost:3000/ --view                 # mobile
npx lighthouse http://localhost:3000/ --preset=desktop --view
```

قِس على build Production فقط (وضع التطوير أبطأ عمداً)، وكرر القياس 3 مرات.
